USER EXPERICIENCE AT CONFIGURATION MENU:

    Multiple sections appear:
        Information(App version, device information, bluetooth version)
        Agronomic Day time period(this defines the "Forecasting Available" zone for the charts. Default 19hrs can be +- 3hrs. Default 9hrs can be +- 3hrs.)
        Location(If location permission granted and enables then automatic pull, or if user wants manual setup on interacive map. If user location != selected device location then use device location)
        Server connection(scheme, ip, port, api_token, automatic sync schedule with customizable time)
        Local Database(Size information, Clear local database, sync with server.)
        Theme(system dark/light)

    If it's the first time configuration the system want's you to complete all important fields: location.
    Configuration can be saved or reverted to default.
